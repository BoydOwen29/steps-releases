# Steps Instituto: descargas

Instalador del programa de gestión del Instituto Steps.

**Descargar:** entrar a [Releases](../../releases/latest) y bajar `Steps-Instituto-Setup-x.y.z.exe`.

1. Abrir el archivo descargado.
2. Si Windows muestra "Windows protegió su PC", tocar **Más información** → **Ejecutar de todas formas**.
3. Se instala solo y crea el acceso directo **Steps Instituto** en el escritorio.
4. Entrar con el mail y la contraseña que te dio el administrador.

Después el programa se actualiza solo: cuando haya una versión nueva, avisa al abrirlo.

Este repositorio tiene solo los instaladores, no el código.
